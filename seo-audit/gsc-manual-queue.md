# Google Search Console — manual "Request indexing" queue

Generated 2026-10-21 from public/sitemap.xml.

Google has no API for requesting indexing of ordinary pages, and the button
in the Search Console UI allows roughly ten URLs a day. This queue is ranked
so the most valuable pages go in first and an abandoned queue still leaves the
ones that matter submitted.

How: Search Console → the search box at the top → paste the URL → Enter →
"Request indexing". Do not re-request a URL that already says it is indexed;
it spends quota and changes nothing.

**Deploy before submitting.** A URL submitted ahead of the deploy gets crawled
as the old page and the fetch is wasted.
